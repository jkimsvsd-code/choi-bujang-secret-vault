패키지 조회 상세

          

        

      


      

        
업무 앱

        
업무 서비스에 접속하지 못할 때 이용 가능 여부와 거부 이유를 확인하세요. 실제 업무 사이트를 여는 기능은 아니며, 예제 결과는 연습용입니다.

        

          

            
업무 앱 이용 가능 여부

            
버튼을 누르면 판정을 한 번 요청합니다. 업무 사이트는 열리지 않습니다.

            

            

              언제 사용하나요?
              
업무 서비스에 접속하지 못하거나 조직에서 접근 상태 확인을 안내했을 때 사용하세요. 직접 접속이 잘 되고 조직의 별도 지침이 없다면 반드시 이 탭을 거칠 필요는 없습니다.

              
실제 판정에는 조직 연결과 권한이 필요합니다. 허용 판정은 실제 서비스 연결 완료가 아니며, 실패해도 자동으로 다시 시도하지 않습니다.

            

          

          

            
확인 결과

            

              
아직 확인한 앱이 없습니다. 목록에서 이용 가능 여부를 확인하세요.

            

          

        

        

          
판정 상세

          

        

      


      

        
보안 기록

        
받아 온 접속·보안 알림의 내용과 이전 조회 이력을 확인합니다. 기록 건수만으로 공격 여부를 판단할 수 없으며, 과거 기록은 현재 상태가 아닙니다. 기록 조회나 AI 설명만으로 조치가 실행되지는 않습니다.

        

          
접속·XDR 기록

          
AI 설명은 기록 식별자만 보내며, 실패해도 기록은 그대로 유지됩니다. 조치는 원천 권한 확인과 별도의 사람 확인을 거칩니다.
