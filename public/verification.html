자료실로 돌아가기

1~11단계 정상·금지 요청 실측 기록

현재: 41종 모두 미실행. 실측 통과 0/41. 아래는 저장소 구현과 단계 기록을 바탕으로 만든 자료실용 시험안입니다. 공식 심판의 41종 목록은 제공되지 않았으므로 공식 목록과 동일하다고 주장하지 않습니다. 기존 모의 검사·이전 배포의 결과를 옮겨 적지 않습니다. 이 페이지는 기록 양식이며 자동 실행·자동 집계 화면이 아닙니다.

한 표에 기록하는 절차

  1. 표를 접근이 제한된 작업 기록에 복사합니다. 실행 묶음 ID, 대상 배포 URL·커밋·단계, 검사 범위, 시험 환경을 표 위에 적습니다. git status --short·git log -1 --oneline과 실제 /aleph.json을 대조합니다. 다른 배포·리디렉션·설정 불명은 확인 불가입니다. 현재 11단계 승인 조건을 모든 보호 요청의 정상 전제로 적용합니다. 과거 단계의 취약한 공개 접근을 복원하지 않습니다.
  2. 시험 A/B·강사·등록/미등록 기기를 준비합니다. 비밀번호·토큰은 공식 입력 화면과 기존 세션으로만 전달합니다. 별도 시험 메모를 쓰고 기존 자료·정책·복원 기준은 보존합니다. 복원·회수·권한 변경 검사는 준비된 시험 대상에서만 수행합니다. 필요한 API나 시험 환경이 없으면 미실행으로 남깁니다.
  3. 각 단계의 정상 요청을 먼저 보내고, 금지 요청, 정상 요청 재확인 순으로 수행합니다. 한 행에 여러 요청이 있으면 T번호에 -a/-b처럼 하위 실행 ID를 붙여 같은 표에 행을 복제합니다. 모든 하위 요청 증거가 있어야 해당 시험 한 종을 통과로 집계합니다. 재시험은 기존 실패 행을 덮어쓰지 말고 새 행으로 추가합니다.
  4. 개발자 도구 → Network에서 실제 API 상태 코드·고정 사유·판정·허용/거부 효과를 관측합니다. 정상 200만으로 소유권 검사가 통과했다고 판단하지 않으며, 금지 요청은 거부 후 자료 비반환·변경 없음도 확인합니다. 401/403 이외에도 계약에 따라 404·405·409 또는 엔진 deny/step_up이 기대 결과일 수 있습니다. 5xx·통신 실패·리디렉션은 금지 요청 통과가 아닙니다.
  5. 서버 응답의 실제 requestId 또는 서버가 발급한 추적 헤더와 그 필드명을 기록합니다. 서버 기록에서 동일 ID·경로·시각·상태를 대조합니다. 제공하지 않으면 “미제공”으로 적고 서버 대조는 확인 불가로 남깁니다. 임의 UUID·T번호·작전실 snapshotId를 실제 요청 ID 대신 쓰지 않습니다. snapshotId는 요약 응답과 operations_summary 기록을 대조할 때만 사용합니다.
  6. 확인 시각은 응답 관측 시각을 ISO 8601과 시간대(예: +09:00)로 기록하고, 서버 시각과 다르면 둘 다 적습니다. 요청 전에는 시각과 ID를 채우지 않습니다. 증거에는 상태·고정 사유·일치 여부·배포 커밋·비식별 요청 ID만 남깁니다. 원본 HAR·전체 헤더·응답 JSON을 첨부하지 말고 토큰·쿠키·이메일·실명·사용자/기기 ID·메모 제목/본문을 제외합니다. 요청 ID 자체에 개인정보가 섞이면 공개 표에서는 제외하고 제한된 서버 기록에서만 대조합니다.
  7. 판정은 미실행 / 확인 불가 / 실패 / 실측 통과로 구분합니다. 요청을 보내지 않음은 미실행, 응답을 받았어도 필수 증거 또는 서버 대조가 없으면 확인 불가입니다. 기대 결과와 다르면 실패입니다. 기대와 실제 응답·효과·동일 요청의 서버 기록이 모두 일치한 행만 실측 통과입니다. 모의 테스트와 과거 심판 점수는 실측 결과 칸에 넣지 않습니다.
  8. 완료 전 정상 허용과 금지 거부의 증거가 모두 있는지 확인합니다. 탐지 propose_revocation만으로 회수 통과를 기록하지 않으며, 회수 후 금지 요청 거부와 영향받지 않은 정상 요청 허용을 각각 실측합니다. 복구 미리보기는 복원 완료가 아닙니다. 41종의 모든 필수 하위 요청이 실측 통과하기 전에는 “41종 통과” 또는 “전체 완료”로 표시하지 않습니다.

명령 node --test test/operations.test.mjs은 요약 표시의 모의 검사만 수행합니다. 이 표의 41종 API 실측을 대신하지 않습니다. 화면에서는 자료실 → 탈환 작전실 → 작전실 요약 새로고침 후, 같은 요약 ID의 가린 서버 기록을 대조합니다.
